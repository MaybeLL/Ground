# Grounds review snapshot

This private review snapshot contains the CLI, terminal UI, workflow skills, and machine-readable contracts. It is not a public release. Package names are temporary, package publication is disabled, and registry version checks are disabled.

Node.js 22.13 or later is required. The source components are in `typescript/` and `tui/`; run `npm ci` and `npm run build` in each directory to build them. No project license or authorization for public distribution has been established.
