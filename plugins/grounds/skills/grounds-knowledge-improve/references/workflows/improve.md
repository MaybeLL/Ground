# 准备知识改进与证据交接

## 出题与独立核题

固定文档/源码范围、允许修改路径和预算。依据开发者真实需要理解的规则、协作边界与异常路径出题，不以冷僻细节制造失败。公开题面应自足；拟定答案、rubric 和源码出处保存在私有目录中。

在用户授权的宿主上交给新上下文核题者：只读指定来源，独立核验每个必答要点是否由题面询问、参考是否确实受源码/文档支持。不能证实的前提标为未知，不能先假定答题者会错。

## 运行能力边界

旧自动实验协调器已退役。**当前不启动基线或复测**；准备好的材料不算成功执行，手工作答不能冒充受限 doc-only 实验。执行请求按 [grounds-eval](../../../grounds-eval/SKILL.md) 明确报告未执行。

已有真实历史答案与评分可以用于诊断，但记录实际版本与材料范围；不能推断当前文档仍有相同缺口。没有实验记录也可以通过源码证据提出文档修复，只能称为来源核验，不称为量化提升。

## 文档修复

按授权修改现有权威主题，保留来源、适用范围和未证实的运行时事实。不粘贴整道标准答案刷题，不修改源码、旧答案、旧评分或实验事实。尊重用户未提交改动。

若保留回归题，修复上下文不得包含其题面、答案或结果。协调者只按主问题白名单交接；可用[材料助手](../materials-helper.md)裁切已存在的合法输入，但字段过滤不能代替真实权限隔离。

## 交接

记录问题/评分版本、来源 commit/路径、已检查事实、文档 diff、待执行的基线与回归及剩余预算。恢复不重置总截止时间。不创建虚假 run，不制造环境验证回执，也不补造缺失答案/trace。

未来执行路径可用后，A/B 应固定题目、标准、模型、工具权限和预算，只改变文档快照；保留全部 attempts。当前交接明确写“效果未测量”，不标记自动闭环完成。
